How to test the StrongHold pull flow:
  1. In the StrongHold app, tap View (or Attach) on a sandbox file — this decrypts it into the temp cache.
  2. Come to this page and open any picker above.
  3. In the picker, open the menu (hamburger) → Show roots → select StrongHold.
  4. Pick the file. The magic-number check below should show a known signature (e.g. %PDF, FF D8 FF for JPEG, 89 50 4E 47 for PNG) — proving the decrypted bytes arrived intact.
Remember: the cache is ephemeral (5-min TTL, purged when you return to the StrongHold app).
